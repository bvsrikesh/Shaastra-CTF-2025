# 🔐 SHAASTRA CTF 2025

### Capture The Flag | Shaastra 2025 | IIT Madras

A collection of cybersecurity challenges, problem statements,
and detailed solution writeups from **Shaastra CTF 2025**,
conducted as part of **Shaastra**, the annual technical festival
of the Indian Institute of Technology Madras.

The competition featured challenges spanning multiple domains
of cybersecurity, designed to test participants' technical
knowledge, analytical thinking, and problem-solving abilities.

## 🧩 Challenge Categories

The competition included challenges across the following areas:

| Category | Focus Areas |
|----------|-------------|
| 🌐 Web Exploitation | Web application vulnerabilities and security |
| 💻 Binary Exploitation | Memory vulnerabilities and binary analysis |
| 🔍 Digital Forensics | Investigating digital artifacts and hidden information |
| ⚙️ Reverse Engineering | Analyzing program behavior and executable logic |
| 🌐 Networking | Network protocols, traffic analysis, and security |
| 🧠 Miscellaneous | Logic, scripting, and unconventional security puzzles |
